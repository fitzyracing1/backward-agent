# Backward Agent

Build AI agents last-to-first. Run them first-to-last.

Site: https://fitzyracing1.github.io/backward-agent/

## Run

```bash
python3 scripts/backward_agent.py --goal "your goal"
```

## Build order

1. Done picture
2. Terminal test
3. Last act
4. Preconditions
5. Gather
6. Intake

Then the run loop.
