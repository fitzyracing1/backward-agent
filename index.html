Build the agent backwards.

Start with the finished artifact and the test that proves it. Then the last act. Then preconditions. Then gather. Then intake. Run the other way.

  1. 01
    Done pictureName the world after success and the exact file that must exist.
  2. 02
    Terminal testA predicate. File exists, size holds, required headings are present.
  3. 03
    Last actThe single write or call that would make the test pass.
  4. 04
    PreconditionsSmallest observable facts the last act needs.
  5. 05
    GatherCheapest observations that produce those facts.
  6. 06
    IntakeRaw line becomes one sentence. Then the loop runs forward.
